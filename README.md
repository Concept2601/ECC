## WoodQuote (Android quotation app)

The [`woodquote/`](woodquote/README.md) folder contains an Android app for quoting joinery: TV stands, kitchens, islands, built-ins and wardrobes. It includes a visual 3D designer, a cut optimiser, an AI diagram reader, and quotations, invoices and receipts.
